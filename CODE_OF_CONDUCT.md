# Contributor Covenant Code of Conduct

Contributors must act respectfully and constructively. Harassment, discrimination, and publication of another person's credentials or private conversation data are unacceptable. Maintainers may remove or restrict contributions that violate this standard.

贡献者应保持尊重和建设性。骚扰、歧视，以及公开他人凭据或私人对话数据均不可接受。维护者可以移除或限制违反该标准的贡献。

Report conduct concerns privately to the project maintainers.

行为问题请私下报告给项目维护者。
