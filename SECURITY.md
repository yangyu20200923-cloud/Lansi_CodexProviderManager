# Security Policy

Report suspected vulnerabilities privately to the project maintainers before opening a public issue. Include a minimal reproduction and affected version. Do not include API keys, auth.json, session JSONL files, database files, backup archives, or conversation content.

发现疑似漏洞时，请先向项目维护者私下报告，再创建公开 Issue。请提供最小复现和受影响版本；不得包含 API Key、auth.json、会话 JSONL、数据库文件、备份或对话内容。

In scope: credential exposure, unsafe configuration writes, incorrect rollback, data loss, and local privilege boundaries.

范围包括：凭据泄露、不安全配置写入、错误回滚、数据丢失和本地权限边界问题。
